YouTube MCP Manager

A private, self-hosted tool for managing the owner's own YouTube channels.

YouTube MCP Manager runs locally on its owner's computer. It is used by Mihai Dafinoiu to manage his own YouTube channels (IndustryXray, Bad Day Field Guide and DoCompass) and to research public YouTube data.

What it does

  • Lists the owner's own videos, playlists and YouTube Analytics statistics.
  • Prepares uploads and metadata changes. Every change must be approved by the owner in a local interface before it runs.
  • Reads public channel and video statistics for research.

The app is not offered to the public and has no user accounts. It uses only the official YouTube Data API and YouTube Analytics API through Google OAuth.
